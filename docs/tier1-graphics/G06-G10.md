## Controls

All selections below require restart. Intensity/strength sliders are live.

| Feature | INI / UI | Default and behavior |
| --- | --- | --- |
| G06 Contact shadows | `graphics_contact_shadows`; `graphics_contact_strength` | Off; strength 0.75, range 0-1. Uses scene depth; independent of PCSS. |
| G07 Volumetric sunlight | `graphics_volumetric_light`; `graphics_volumetric_intensity` | Off; intensity 1, range 0-3. Uses directional resolve/depth and primary diffuse tint. |
| G08 Point-light volumetric fog | `graphics_point_fog`; `graphics_point_fog_intensity` | Off; intensity 1, range 0-3. Collects/de-duplicates local lights and retains bounded, fading light memory. |
| G09 Directional filtering + cascade blend | `graphics_directional_filter` | Off; atlas-safe filtering and guarded 10% cascade overlap. Does not force PCSS on. |
| G10 Directional shadow resolution | `graphics_shadow_resolution=0/1/2` | Original / 4096 atlas / 8192 atlas, four cascades. Original preserves authored profile selection. |
| G10 Local shadow resolution | `graphics_local_shadow_resolution=0/1/2` | Original / point-base 1024 + spotlight-base 2048 / point-base 2048 + spotlight-base 4096. Each retains four native tiers. |

Both launchers group these settings under **Shadows and volumetric lighting**.
The native overlay also exposes them with stable preset-selection keys and its
existing restart indication. Settings save/load, custom presets and the two
immutable RTX 3070 profiles retain their existing behavior. New settings default
off or Original; they do not modify an existing installation's configuration.
Higher shadow maps consume more VRAM; use High before trying Ultra on an 8 GB GPU.

## Rendering and compatibility

- Contact and directional filtering use the existing shadow-resolve/blur resource
  chain. PCSS retains its earlier toggle. G09 alone requests the atlas-safe filter;
  cascade blending is nonzero only after its matching native overlap hook installs.
- Directional and point fog have independently selectable output contributions.
  They share captured shadow/depth/tint resources. Missing or incompatible inputs
  decline the effect instead of applying an unproven resource layout.
- Light collection observes only known point-light shader families and validates
  guest-memory ranges. The current upstream steady-fog helper bounds the light list
  and fades disappearing lights to reduce camera-dependent popping.
- Volumetric composition targets the exact current scene before NR/SR, after the
  existing SSGI stage. An HDR-post fallback handles the original post path. The
  captured result is consumed once; NR, transparency and UI are not given a second
  additive fog pass. Scene/proxy dimensions and image identity are checked.
- GPU images and views follow the existing scheduler's deferred retirement paths.
  Disabled effects allocate no extra effect GPU images or pipelines. No new GPU
  drain is inserted into NR Prepare. Camera-dependent contact effects retain the
  existing valid-camera requirement; use DLAA, TAA or an upscaler for testing.
- Shadow resolution and cascade changes patch only the loaded, byte-verified guest
  image at startup. They do not edit the dump on disk. Point and spotlight patches
  are separately guarded; filter-radius tuning is restricted to successful patches.
  A mismatched code site logs the refusal and retains that native path.
- Cascade overlap needs saved XMM0 and the incoming RAX. A new opt-in hook mode
  preserves that context; the existing hook emission path remains the default.
  Only the cascade hook opts in. This avoids replacing the global hook framework
  or changing the working picture/NR hooks.

G11's replacement point-light shadows, G12 and G13 are outside this batch.
G10 only increases the game's existing point/spotlight shadow-map quality.

## Reproduce

Start with complete applied v1.0.3 NR source, then apply supplements in order:

```powershell
python tools/apply-tier1-gtao.py C:\path\to\engine
python tools/apply-tier1-lighting.py C:\path\to\engine
python tools/apply-tier1-atmosphere-shadows.py C:\path\to\engine --check
python tools/apply-tier1-atmosphere-shadows.py C:\path\to\engine
```

The new maintained supplement is `engine/tier1-atmosphere-shadows.patch` with its
per-file hash manifest. The helper checks preimages and stages/replays the entire
patch before writing source changes. The complete engine in a source ZIP is
already applied: build it directly without reapplying historical patches.

## Acceptance pass

Configure this candidate separately with a separate save folder and your own NR
runtime if desired. Keep your earlier graphics settings and enable the new
features explicitly; the package starts with clean defaults.

1. Check Contact shadows alone, then with PCSS and G09, around feet, rails, stairs
   and sunlit wall corners. Check cascade boundaries while moving the camera.
2. Compare directional sunlight and point fog separately, then together, in a
   sunlit courtyard and around lamps in a dark interior. Check intensity zero,
   moving/turning away from lamps, menus and area transitions.
3. Restart with shadow quality Original, then High. Check both sun shadows and
   existing local light shadows. Try Ultra only if memory/cost remains acceptable.
4. Repeat with NR off and your normal NR single/multipass settings, then DLAA and
   reduced presets. Check for double fog, shifted shadows, temporal trails or
   missing UI. Retain logs if any guarded effect declines or a visual issue occurs.
5. Switch new features off, restart and compare against rc2 using the same scene.

Gameplay, HDR/FG coexistence, performance and long-session acceptance remain
separate from compile, fixture and synthetic GPU checks. See the batch validation
report and the candidate's PACKAGE-CHECKS.json / VALIDATION.md for measured scope.
